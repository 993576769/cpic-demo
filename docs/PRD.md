# 保险经纪助理 — Clickable Demo PRD

> **文档目的**: 给 AI coding agent（Claude Code / Codex / Gemini 等）一份能直接照着跑出 clickable demo 的产品需求文档。
> **demo 性质**: 纯前端可点击演示，**不连真实接口、不持久化数据**，所有数据用截图里出现的文案作为 mock。
> **目标观众**: 太平洋保险等保险公司管理层 / 业务团队的演示场景。

---

## 1. 项目背景

保险经纪人日常痛点：知识体系庞杂沉淀慢、客户洞察靠记忆、老保单缺口判断难、客户跟进无优先级、获客渠道单一。本工具是基于企业微信生态的"经纪助理"小程序，提供智能工作台 + AI 客户热度模型 + AI 跟进方案生成 + 自动客户旅程 + 运营任务批量触达 + 智能内容运营 + 智能活动邀约 七大核心能力。

本次 demo 目标：把所有核心页面跑通一条**可点击的体验链路**，让观众能从首页一路点到底，看到状态变化（如 tab 切换、勾选、提交）。

---

## 2. 技术约束

| 项 | 要求 |
|---|---|
| 形态 | 移动端 H5 或 React 小程序模拟（推荐 React + Vite + TailwindCSS） |
| 屏幕尺寸 | 按 iPhone 14/15 标准视口（375 × 812）设计，移动端 viewport |
| 顶部状态栏 | 保留截图里的 09:25 / 信号 / WiFi / 电池 样式即可，不接系统 API |
| 右上角胶囊 | 保留截图里的 `···` 和 `⊙` 小程序胶囊样式（纯装饰，不可点击） |
| 数据存储 | 无后端，状态用 React state / Context 即可；**不要用 localStorage** |
| 假数据 | 全部来自 figma 截图里的文字，不要自己编造 |
| 动效 | **不需要动效**，按钮点击有最基础的 active 反馈即可 |
| 路由 | 用 React Router 或同级方案，每个页面有独立 URL，方便测试 |
| 字体 | 系统默认（中文：苹方 / PingFang SC；西文：sans-serif） |
| 主色 | 黑色 `#000000`（按钮主色）、白色 `#FFFFFF`（背景）、浅灰 `#F5F5F7`（卡片底）；强调色蓝 `#3D7BFF`（仅用于打开率等数据强调） |

## 7. 完整路径汇总（点击流）

```
/home  →  快捷工具"拜访记录分析"  →  /customers/wang/visit-record

       →  勾选 + "添加到待办事项"  →  /customers/wang/todo-list
       →  返回 /home
```

### 路径 B — 为你推荐主流程
```
/home  →  为你推荐"重点客户"卡片"定制贺卡"  →  /customers/wang
       →  "生成下一步"  →  /customers/wang/followup
       →  "生成待办事项"  →  /customers/wang/followup/tasks
       →  /customers/wang/todo-list
```

### 路径 C — 工具流
```
/home  →  底部 tab "工具"  →  /tools
       →  分别进入各工具：
         · 素材库  /material  →  /material/content?type=education  →  /material/moments/publish
```

## 8. 推荐 demo 演示路径

第一次给观众演示时，**建议按下面顺序展示**，能讲完所有核心价值点：

1. **打开 = 首页**：展示分类 tab、任务勾选、为你推荐（切换 3 个 tab）
2. **快捷工具 → 拜访记录分析**：输入 / 发送 / AI 分析展开 / 生成跟进方案
3. **进入跟进方案**：看 AI 推荐方案、话术、生成待办
4. **多类任务拆解**：切分类 tab、勾选、全选、加入待办列表
5. **多日待办列表（静态）**：看到未来 5 天的执行安排
6. **返回首页 → 底部 tab "顾客"**：展示标签模式 ↔ 四象限模式切换
7. **点客户行 → 客户详情**：滚动看热度模型、AI 推荐切入点、家庭结构、保单缺口
8. **底部 tab "工具" → 用户旅程管理**：D1/D3 切换 + 批量发送 modal
9. **回到工具 → 运营任务**：去完成 → 批量发送
10. **回到工具 → 素材库 + 朋友圈**：从素材库选 → 发布朋友圈
11. **回到工具 → 活动邀请**：活动详情 → 邀约名单 → 批量发送邀请函 / 邀约记录
