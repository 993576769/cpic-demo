### 兼容iPhoneX底部 button-fixed-bottom
- 需要定位在最底部的组件，使用`button-fixed-bottom` 组件包裹起来，自动会在`iPhone X`等设备添加底部保护区域
- 示例代码：
```
<button-fixed-bottom>
  内容
</button-fixed-bottom>
```
#### 事件
| props   |  类型  | 默认值 | 描述 |
| :------ | :----: | :----: | :--- |
| bgColor | String |  #fff  | 颜色 |
| zIndex  | Number |   99   | 颜色 |
